Guia Rápido de Uso

            
        

        

            
    
                
  1. Dados Básicos: Preencha Telefone, Nome e Ocorrência. Use os botões rápidos para autocompletar textos.
    2. 
                
  2. Histórico: O sistema salva as últimas 10 entradas. Use o menu suspenso para reaproveitar dados.
    3. 
                
  3. PDFs Base: Arraste arquivos. Para excluir páginas de um PDF, digite os números separados por vírgula (ex: 1, 3).
    4. 
                
  4. Imagens: Arraste imagens. Clique em 🔍 para extrair Nome e Telefone via OCR automaticamente.
    5. 
                
  5. Ajuste do Quadro: Em "Ajustes Manuais", mova o quadro de ocorrência no eixo X/Y ou altere a página alvo.
    6. 
                
  6. Finalização: Confirme o preview à direita e clique em 💾 Download.
